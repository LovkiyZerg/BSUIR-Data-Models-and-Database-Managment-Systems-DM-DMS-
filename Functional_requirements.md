# Функциональные требования — Conquerors Blade DB

1. Аутентификация и авторизация

FR-1.1 Игрок может зарегистрироваться, указав username, email и пароль.
FR-1.2 Пароль хранится только в виде хеша.
FR-1.3 Игрок может войти в систему по email и паролю.
FR-1.4 При успешном входе создаётся игровая сессия с ограниченным сроком жизни.
FR-1.5 Игрок может выйти из системы (сессия инвалидируется).
FR-1.6 Доступ к операциям возможен только для аутентифицированных игроков.

2. Управление игроками

FR-2.1 Администратор может создать нового игрока.
FR-2.2 Администратор может просмотреть список игроков и карточку отдельного игрока.
FR-2.3 Администратор может изменить данные игрока
FR-2.4 Администратор может заблокировать или удалить игрока
FR-2.5 Игрок может просматривать и редактировать свой профиль.
FR-2.6 Игрок может сменить пароль.

3. Система ролей

FR-3.1 В системе существует минимум три роли: admin, moderator, player.
FR-3.2 Администратор может назначать и снимать роли с игроков.
FR-3.3 Права доступа определяются ролью:
    player — играет матчи, создаёт персонажей, вступает в гильдии.
    moderator — имеет право блокировать игроков.
    admin — управляет игроками, ролями, имеет полный доступ.

4. Журналирование действий 

FR-4.1 Система логирует значимые действия: вход, выход, создание/изменение/удаление персонажей, участие в матчах, вступление в гильдии.
FR-4.2 Запись лога содержит данные
FR-4.3 Логи доступны только admin/moderator.
FR-4.4 Логи не удаляются игроками.

5. Управление персонажами

FR-5.1 Игрок может создать персонажа, указав имя.
FR-5.2 Один игрок может иметь несколько персонажей.
FR-5.3 Игрок может переключаться между своими персонажами.
FR-5.4 Игрок может удалить персонажа.
FR-5.5 Персонаж имеет уровень и набор характеристик.
FR-5.6 Персонаж может быть экипирован оружием и отрядами.

6. Управление матчами

FR-6.1 Система создаёт матч с указанием карты, режима и времени начала.
FR-6.2 Матч рассчитан на 30 игроков (15 на 15).
FR-6.3 Матч не может начаться, пока не набрано нужное количество участников.
FR-6.4 Игрок может присоединиться к матчу только одним персонажем.
FR-6.5 Игрок имеет ограниченое количество отрядов в матче.
FR-6.6 Каждый участник матча распределяется в команду (атака / защита).
FR-6.7 По завершении матча фиксируется статистика каждого участника: убийства, смерти, помощь, счёт.
FR-6.8 Определяется команда-победитель.
FR-6.9 Игрок может просматривать историю своих матчей и статистику.

7. Управление отрядами

FR-7.1 В системе существует каталог отрядов (пехота, кавалерия, лучники) с уровнями (tier) и характеристиками.
FR-7.2 Отряды доступны для найма персонажем.
FR-7.3 Персонаж может иметь разные отряды.

8. Управление оружием и экипировкой

FR-8.1 В системе существует каталог оружия с типами, редкостью и характеристиками.
FR-8.2 Персонаж может владеть несколькими единицами оружия.
FR-8.3 Только одно оружие может быть экипировано одновременно.
FR-8.4 Игрок может продать или выбросить оружие.

9. Управление гильдией

FR-9.1 Игрок может создать гильдию, указав название.
FR-9.2 Игрок может вступить в гильдию или покинуть её.
FR-9.3 Гильдия имеет роли участников: leader, officer, member.
FR-9.4 Лидер может назначать офицеров и исключать участников.
FR-9.5 Игрок может состоять только в одной гильдии одновременно.
FR-9.6 Лидер может распустить гильдию.

10. Статистика

FR-10.1 Просмотр списка матчей с фильтрами по карте, режиму и дате.
FR-10.2 Отчёт по активности игроков за период (количество матчей, суммарный счёт).
FR-10.3 Топ игроков по убийствам/счёту за сезон.
FR-10.4 Статистика гильдий: количество участников, суммарный счёт.
FR-10.5 Список самых популярных оружий и отрядов.
